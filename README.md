素材製作工坊：https://sixteenpct.github.io/ffxiv_journey/collection/workbench/

## 網站階層

- 根目錄：Journey 總首頁，三大分館、六大入口平等陳列。
- collection/workbench/：素材製作工坊。
- 尚未開放的館藏維持入口說明，不建立假連結。

## 維護與發布規則

本 repo 是公開靜態網站的發布位置，GitHub Pages 使用 main 分支根目錄。
工坊維護正本仍在 Sixteenpct/ffxiv_collection 的 docs/；Journey 首頁正本在該 repo 的 docs/journey/index.html。
修改先在維護正本完成與驗證，再將核准的公開檔案同步至本 repo，禁止反向覆蓋正本或搬入私人資料、個人存檔。
工坊六個執行檔完整同步到 collection/workbench/，保留原有儲存鍵及資料格式。
每次同步核對 Git blob SHA、相對資源路徑及 Pages 部署結果；不使用 force push。
Sixteenpct/ffxiv_workbench 與既有網址先保留為相容版本；後續正式更新以本 repo 為發布目標，避免雙線維護。
新增分館沿用清楚階層與繁體中文，不以內部課程代號作前台分類。
