# 職業講義固定視覺規範

本人裁決：2026-10-11。適用所有現在及未來正式職業講義；目錄與學院大廳維持自己的版型。

## 技能卡與章節標題

- 技能卡的圖示及整組文字一律頂端對齊，不使用垂直置中。左右卡描述行數不同時，技能名稱也要從同一高度開始。
- 每個項目區塊只有一行章節標題，採 `兩位數章節編號 · 中文章節名稱`，與該頁側欄對應名稱一致，例如 `04 · 獸魂與戰嚎`、`02 · Lv.50·技能箱`。刪除原標頭的說明式主標題（例如「先判斷危險，再選擇補或打」），不刪正文教學。忍者講義亦採此規則。
- 章節名稱使用語意化 h2，保留原副標題金棕色 #967e56、字重 800；放大至原說明式主標題的字級 clamp(19px,2vw,22px)，手機 19px、line-height 1.38、letter-spacing .06em。正文沿用已核准閱讀節奏。

## 橫幅及背景

- 每堂職業課必須同時有總標題橫幅圖與頁面背景圖。橫幅一律使用該職業的繁中官方職業指南插畫（guide_header.jpg），依白魔／戰士形式加深色遮罩；忍者也採同樣規則。整頁底圖一律使用該堂練習場地的圖片，不以職業插畫代替。場地須與 course-config 的完整副本名稱一致；同職業不同場地的課程各自配置。
- 所有職業沿用忍者橫幅尺寸：桌面寬度 ≥901px 的 banner 固定 166px（按忍者原實際約 165px 高度取整）、上下內距 12px／14px；621–900px 以 166px 為最低高度並允許文字換行自然增高，620px 以下沿用共同自然高度。不得為白魔、戰士或後續職業另造高低不同的預設橫幅。窄窗文字換行不可被裁切。
- 橫幅加深色遮罩保障標題可讀；背景刷淡，正文卡片仍容易閱讀。R005 保留密約之塔底圖、R022 保留龍巢神殿底圖；白魔 R001 用披雪大冰壁、戰士 R014 用帝國南方堡。
- 圖片在製作時選定、下載到 repo，HTML／CSS 直接寫固定相對路徑。所有頁面圖片（含技能圖示）禁止在開頁時搜尋、隨機挑圖或透過外部 API 動態取得，不熱連結外站圖片。正常瀏覽器讀取及快取靜態檔案不屬動態選圖。
- 來源、版權及雜湊保存在對應來源記錄；圖片僅作裝飾時，不冒充現行機制或實機戰鬥證據。新增正式講義前確認圖片已存在並納入提交。

## 延伸閱讀

- 使用 ol 編號清單；第一項固定為該職業的講義總索引（帶 ?job= 篩選），最後一項固定為該職業的「繁中官方職業指南 ↗」。相關講義位於中間。

## 瀏覽器圖標（favicon）

- 所有職業課程專頁統一使用目前忍者講義的 `assets/favicon-ninja.svg`，不依各職業改用其他圖標。學院與目錄頁沿用館別圖標。

## 共用實作與驗收

- `lecture-presentation.css` 是上述共用視覺規則的實作，每份正式講義在職業 CSS 之後載入，不把規則複製成每職一套。
- 檢查技能卡頂端對齊、單行章節標題／字級、橫幅高度、兩種圖片實際顯示、靜態引用可解析、sticky 導覽與章節定位；發布後驗證剛提交版本的 Pages。
- 不因視覺修正改寫教學、課程完成狀態或私人學習資料。

## 全站上下捲動

- 所有既有及未來 FF14 Journey 公開頁的「捲到底部」及「TOP」按鈕共用 assets/scroll-tools.js，以 requestAnimationFrame 執行固定 180ms 三次緩出動畫，終點限制在實際可捲範圍；連按取消前一動畫。prefers-reduced-motion 時直接定位。此規則包含素材製作工坊、職業養成學院、講義索引、內容專修及所有職業講義；沒有按鈕的頁面不額外新增按鈕。舊 pve/courses/scroll-tools.js 保留相同實作供快取 HTML 相容。

## 章節閱讀細節｜2026-10-11 最新追修

- 章節標題色帶上下內距為 10px／11px，較原 7px／8px 各增加 3px；桌面及手機一致，原水平內距保留。
- 所有職業講義的側欄頂端只寫「課堂章節」，不再附職業與等級。
- 正文內 h3 小標題一律在前方加圓點項目符號，沿用原字級與顏色；換行不跑到符號下方。
- 公開職業講義刪除「本頁以職業養成為主；完整路線與 Boss 專修另屬 PvE 內容學程，不能因這堂使用同一場地，就把內容專修視為結課。」及白魔、忍者 Lv.56 同義說明。兩學程分工仍由 Git 管理，不在講義正文重複展示此施工／進度提示。
