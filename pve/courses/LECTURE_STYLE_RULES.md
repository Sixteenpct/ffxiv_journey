# 職業講義固定視覺規範

本人裁決：2026-10-11。適用所有現在及未來正式職業講義；目錄與學院大廳維持自己的版型。

## 技能卡與章節標題

- 技能卡的圖示及整組文字一律頂端對齊，不使用垂直置中。左右卡描述行數不同時，技能名稱也要從同一高度開始。
- 區塊主標題上方的副標題採 `兩位數章節編號 · 中文章節名稱`，與該頁側欄對應名稱一致，例如 `04 · 獸魂與戰嚎`、`02 · Lv.50·技能箱`。忍者講義亦採此規則，不保留英文代碼式副標題。
- 副標題統一 15px、line-height 1.6、letter-spacing .06em；字級不得再被舊 reader 或職業 CSS 覆蓋成 10.5px。主標題與正文沿用已核准閱讀節奏。

## 橫幅及背景

- 每堂職業課必須同時有總標題橫幅圖與頁面背景圖，不能只用漸層代替。可共用同一張適合的職業圖片，也可使用已確認的職業／練習場地照片。
- 所有職業沿用忍者橫幅尺寸：桌面寬度 ≥901px 的 banner 固定 166px（按忍者原實際約 165px 高度取整）、上下內距 12px／14px；621–900px 以 166px 為最低高度並允許文字換行自然增高，620px 以下沿用共同自然高度。不得為白魔、戰士或後續職業另造高低不同的預設橫幅。窄窗文字換行不可被裁切。
- 橫幅加深色遮罩保障標題可讀；背景刷淡，正文卡片仍容易閱讀。忍者現有橫幅及背景選圖保留。
- 圖片在製作時選定、下載到 repo，HTML／CSS 直接寫固定相對路徑。所有頁面圖片（含技能圖示）禁止在開頁時搜尋、隨機挑圖或透過外部 API 動態取得，不熱連結外站圖片。正常瀏覽器讀取及快取靜態檔案不屬動態選圖。
- 來源、版權及雜湊保存在對應來源記錄；圖片僅作裝飾時，不冒充現行機制或實機戰鬥證據。新增正式講義前確認圖片已存在並納入提交。

## 瀏覽器圖標（favicon）

- 所有職業課程專頁統一使用目前忍者講義的 `assets/favicon-ninja.svg`，不依各職業改用其他圖標。學院與目錄頁沿用館別圖標。

## 共用實作與驗收

- `lecture-presentation.css` 是上述共用視覺規則的實作，每份正式講義在職業 CSS 之後載入，不把規則複製成每職一套。
- 檢查技能卡頂端對齊、中文副標題／字級、橫幅高度、兩種圖片實際顯示、靜態引用可解析、sticky 導覽與章節定位；發布後驗證剛提交版本的 Pages。
- 不因視覺修正改寫教學、課程完成狀態或私人學習資料。
