## 查閱體驗

保留六堂職業講義、D029、21 職業精修版型、原生分類下拉、薄荷綠／晴空藍表格與既有閱讀介面。職業目錄增設教材主題；關鍵字搜尋課號／主題／職業／場地，可同時套用職業與同步篩選。內容目錄搜尋課號／內容 ID／名稱，與版本篩選共同使用。

搜尋以空白分隔關鍵字、全部符合；忽略英文字母大小寫與全半形。網址 q／job／sync／version 記住目前条件，重新開啟能復原。重置只清除查找條件，不會刪除任何使用者資料，因此直接執行。結果數量與零結果說明即時更新，無 JavaScript 仍能讀全部教材。這是目錄搜尋，沒有全文索引講義正文。

目錄以 14px 資料表保留查阅密度，主要內容不收合。新增主題欄後，窄窗只在表格容器橫向捲動。講義正文、學院職業卡與全站既有 180ms 捲動工具不改。跨頁連結新分頁；PVE 麵包屑純文字；全站 favicon 與三行 footer 維持。

## 紀事收錄與發布

清單欄位：日期／學程／課號／主題；主題連至正式文章，文章再連相關教材。新到舊排列，不做大型年表。每篇聚焦理解突破、概念接點或值得再次檢查的問題，不寫流水帳，也不從結課自動推定存在紀事。首期零篇，空狀態是實際收錄狀態。

草稿與完整核准收據保留私人來源。先詢問是否要編寫，提供完整正文與全部索引欄位給本人審閱；須取得收錄同意與該版公開同意，才可寫入公開 Git（包括公開分支）。既有私人完成日期、熟練度、問答、撤回心得均不視為授權。

`pve/journal/entries.json` 只允許已核准、同意公開的輸出 metadata。每筆必有 id／date／track／course／title／href；approval 只帶 owner=LiouLiou、status=approved、publication=public、approvedAt、contentSha256、indexSha256。不得把核准收據原文或待審稿存到公開 manifest。indexSha256 為前六欄以該鍵順序 JSON.stringify 後的 SHA-256，正文雜湊為對應完整 HTML 位元組。核准應包含文章外觀所承載的實際內容與這六個索引欄位。指紋不能代替真人核准，不得自行生成假的收據。

取得真實核准並準備正式文章後：`node scripts/build-journal.mjs --write`；提交前跑 `node scripts/build-journal.mjs`。生成器拒絕未核准、未同意公開、錯誤學程、索引或正文改動，以及 journal 目錄中的未列管稿件。它是本地發佈前檢查，本期未新增遠端 CI，不能稱為伺服器強制保護。核准後改正文／索引要重新審閱並更新指紋。

## 本期驗證與限制

- favicon／三行 footer：15 頁通過；21 職圖示、名單與分組通過。
- DOM 驗證：166 項，包括既有 job URL、職業＋同步＋搜尋、全半形、複合詞、空結果、重置、popstate、D029 版本、資產連結、表格欄位數与新分頁。
- 發布閘門：一個虛構正例及七個拒絕案例，涵蓋未審、未公開、索引變更、正文變更、越界路徑、工作技術混入及孤立草稿。fixtures 僅暫存，沒有寫入網站。
- 舊 check-job-icons 的兩個 class 比對仍停在已被核准取代的設計，本批修成 class token 比對；URL 靜態檢查改配合通用 query 還原，實際 job 行為另以 DOM 驗證。
- 環境未提供 control-browser，依 Sites 規則未啟動預覽或替代瀏覽器。已做 DOM／靜態與部署驗證，桌面／手機實際視覺尚待本人驗收。
